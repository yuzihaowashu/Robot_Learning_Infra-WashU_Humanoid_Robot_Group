# Progress Log - 2026-05-03

## Teleoperation Safety And Startup

- Fixed single-arm startup so the inactive arm can stay in the relaxed pose instead of moving to the outward stretch pose.
- Updated deploy and park motions to use safer staged paths, including outward clearance before forward-ready poses.
- Slowed the motion into the forward pose to reduce collision risk around the legs.
- Reduced startup arm drop by improving the controller handoff and holding the current arm pose during launch.
- Changed launch behavior so Dex3 hands stay compact until the arms reach outward clearance, then open.
- Simplified stop/relax behavior to avoid redundant outward-stretch transitions.

## Recording Controls And UI

- Changed the XR button mapping so `Right A` saves an episode and `Right B` discards the current episode.
- Added episode discard support to `EpisodeWriter`.
- Changed `Left Y` from reset-pose behavior to a splitter transition marker.
- Updated the VR HUD to show recording state and the current splitter phase.
- Reset splitter phase back to `forward` when a new episode starts or after an episode is saved.
- Updated the Gradio UI label from "Auto Splitter" to "Episode Splitter".

## Task Presets And Splitter

- Moved task definitions into `tasks/task_list.json` instead of hardcoding them in the UI.
- Added task presets for shaking a bottle, placing the bottle into a paper box, and taking the bottle out of the paper box.
- Added `tasks/splitter_list.json` for configurable episode splitting.
- Added a bottle in/out continuous splitter with forward/backward phase definitions.
- Preserved raw continuous recordings under `bottle_in_out_raw` and wrote split episodes under task-specific directories.
- Updated splitter logic to use manual `Left Y` transition markers when available.
- Set `pre_grasp_frames` to 36 and added non-overlap clamping for adjacent split segments.

## Data Checking And Replay

- Added `utils/check_xr_episode.py` to validate XR recordings.
- Added `utils/replay_xr_episode.py` for visual replay videos.
- Added `utils/replay_xr_robot_arm.py` for real-robot arm trajectory replay with dry-run checks and staged startup.
- Fixed zero-frame recordings by saving the image buffer correctly.
- Checked the latest split data and confirmed the generated split episodes are readable.

## LeRobot And Hugging Face

- Added `utils/xr_to_lerobot.py` to convert split XR recordings into a LeRobot-style dataset.
- Generated a local dataset at `xr_recordings_lerobot`.
- Verified the LeRobot output:
  - 138 episodes
  - 18,421 frames
  - 138 parquet files
  - 138 MP4 videos
  - 2 tasks
  - state dimension 63
  - action dimension 31
- Uploaded the dataset to Hugging Face:
  - `https://huggingface.co/datasets/DependableDavid/g1-bottle-in-out`

## Repository Hygiene

- Added `xr_recordings/` and `xr_recordings_lerobot/` to `.gitignore` so recorded data stays out of the code repository.
- Kept raw and converted datasets local/Hugging Face only, instead of committing them to GitHub.
