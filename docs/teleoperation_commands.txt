# =====================
# 关键参数说明
# =====================

# --input-mode=controller  扳机线性插值控制手指开合 (Gradio 只开放此模式)
# --input-mode=hand        CLI 兼容保留；当前 Gradio 不开放，避免误选
# --retarget-type=dexpilot 6对向量差分优化 (xr_teleoperate 原版)
# --retarget-type=vector   3指尖位置优化 (Psi0 风格，更简单快速)
# --motion / --no-motion   默认 --motion: 保持腿部 balance/Unitree motion controller 开启，并通过 rt/arm_sdk 控手臂
#                          只有 bench/debug 或明确不需要腿部平衡时才用 --no-motion
# --record                 启用录制功能 (Left X 开始 episode, Right A 保存 episode)
# --ipc                    启用 ZMQ IPC (Gradio 面板自动加)
# --force-zmq-video        强制用 host PC 的 ZMQ 帧给 PICO 显示，避免 PICO 直连 PC2 WebRTC
# --mirror-vr / --no-mirror-vr
#                           PC monitor 上显示/关闭 VR Mirror 旁观窗口
# --vr-pose-jump-threshold 单帧 controller wrist target 跳变阈值，默认 0.15m；超过会暂停 tracking
# --vr-pose-filter-alpha   controller wrist target 平移低通滤波 alpha，默认 0.35
# --teleop-start-ramp-sec  Left X 开始/恢复后，从当前机器人手臂姿态平滑过渡到 IK 目标的时间，默认 2.5s
# --park-arms-on-stop=spread|default
#                          最终退出时手臂停车位；spread 更安全，default 会暂停 arm_idle_holder

# =====================
# 常用排查
# =====================

# 视频流全黑:
#   → PC2 的 teleimager-server 没启动，SSH 过去重启
#
# PICO 页面打不开:
#   → 先确认已点击 Gradio 的 Launch Teleop；8012 由 TeleVuer 启动，不是 Gradio 启动
#   → URL 必须带 ?ws=wss://<PC_WiFi_IP>:8012
#   → 确认 PICO 访问的是 WiFi IP，不是 192.168.123.x
#   → sudo ufw allow 8012/tcp
#
# PICO 页面能打开但不能 Enter VR:
#   → HTTPS 证书不被 PICO 信任，或证书不是用当前 WiFi IP 生成
#   → 重新运行 bash run_xr_session.sh 生成证书，再在 PICO 接受/信任
#
# Launch Teleop 后很快退出:
#   → 查看 Gradio Output 或 teleop_latest.log 的最后报错
#   → 常见原因: PC2 teleimager 未启动、相机配置不可读、DDS 网络接口不对

# 手臂失控:
#   → 确认 robot_arm.py 中只对腰部施加重力补偿 tau，手臂 tau=0
#
# 手臂突然向后/侧向跳:
#   → 这通常是 PICO/OpenXR controller pose 单帧跳变或重定位
#   → 当前代码会检测 >0.15m 的 wrist target 跳变并暂停 tracking
#   → 在 PICO 中把双手放回安全位置，再按 Left X 重新校准/恢复
#
# 按 Left X 开始时手臂突然下落:
#   → 人手已经向前/向下伸时，第一帧 IK target 可能离机器人当前安全外展位很远
#   → 当前代码会用 --teleop-start-ramp-sec 做启动缓冲，默认 2.5s
#   → 开始前仍建议把双手抬到桌面上方安全高度，再按 Left X

# 右手不动:
#   → 检查日志 [Hand DBG] R_state 是否有异常值 (如 -238)
#   → 如有，断电重启机器人清除编码器故障
#   → 确认用的是 threading.Thread 而非 multiprocessing.Process

# DDS 无通信:
#   → 确认网络接口名: ip link show (通常是 enp2s0)
#   → ChannelFactoryInitialize(0, "enp2s0")
